# Group I Endpoint Security

## Project Title

Behavioral Detection of File-Encrypting Ransomware on Windows Endpoints Using Machine Learning

## Project Overview

This project focuses on developing a behavioural detection approach for identifying file-encrypting ransomware activities on Windows endpoints using machine learning techniques.
